# 云鲜甄选离线数仓项目
> 生鲜新零售连锁企业 · 离线大数据分析平台

**背景**：生鲜新零售连锁企业，含门店销售、B2C电商、批发、团购、商品自营五条业务线，线上线下一体化经营。业务积累了海量交易、会员与库存数据，需搭建离线数仓支撑精细化运营。
**需求**：销售+会员+供应链+商城四大需求。其中，销售分为核销与售卖主题，本次项目仅完成核销与会员主题<br>**数据源**：MySQL、SQL Server<br>**技术**：CDH(HDFS/Hive) + DataX + Presto + PostgreSQL + DolphinScheduler + FineReport。
