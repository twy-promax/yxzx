# 云鲜甄选离线数仓项目
> 生鲜新零售连锁企业 · 离线大数据分析平台

**业务**：云鲜甄选是一家生鲜新零售连锁企业，有五条业务线：门店销售、B2C 电商、批发、大客户团购、商品自营，线上 + 线下双渠道经营。
**目标**：随着生鲜电商行业迅速发展，公司各业务线（门店、电商、批发、团购）累计了大量交易、会员、库存数据。为了从已有数据中挖掘价值，搭建**云鲜甄选大数据处理平台**，对全渠道业务数据进行分析，实现精细化运营，最终提升用户数量与活跃度、提高商品销量、降低运营与损耗成本。
**需求**：销售+会员+供应链+商城四大需求。其中，销售分为核销与售卖主题，本次项目仅完成核销与会员主题
**技术**：CDH(HDFS/Hive) + DataX + Presto + PostgreSQL + DolphinScheduler + FineReport。
